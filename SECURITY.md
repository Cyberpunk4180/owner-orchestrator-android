# Security policy

This repository contains only an Android client and public CI. Do not commit:
tokens, OAuth client secrets, session cookies, private signing keys, keystore,
wallet seed phrases, payment records, customer data, private build logs,
or source code from Aegis, USA-1 or other private projects.

No production releases or signed APKs are authorized here.
Only standard GitHub-hosted runners. Do not enable external CI dispatch,
privileged pull_request_target workflows, or deploy credentials.
